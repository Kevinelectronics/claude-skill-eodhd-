# EODHD MCP — Quick Reference

## Available MCP tools (prefix: mcp__eodhd__)

| Tool | Purpose |
|------|---------|
| `get_technical_indicators` | RSI, MACD, SMA, EMA, Bollinger Bands |
| `get_fundamentals_data` | P/E, EPS, margins, balance sheet, dividends |
| `get_historical_stock_prices` | OHLCV daily/weekly/monthly |
| `get_support_resistance_levels` | Pivot-based S/R levels |
| `stock_screener` | Filter stocks by fundamentals + technicals |
| `get_live_price_data` | Real-time delayed quotes |
| `get_upcoming_earnings` | Earnings calendar |
| `get_company_news` | Recent news by ticker |
| `get_insider_transactions` | SEC Form 4 insider activity |
| `get_macro_indicator` | GDP, CPI, unemployment, rates |

## Ticker format examples
- US stocks: `AAPL.US`, `TSLA.US`, `NVDA.US`
- UK: `VOD.LSE`
- Crypto: `BTC-USD.CC`, `ETH-USD.CC`
- ETFs: `SPY.US`, `QQQ.US`
- Indices: `GSPC.INDX` (S&P 500), `NDX.INDX` (Nasdaq)
